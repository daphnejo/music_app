# Solfedjio Mobile

Native Android/iOS client for the Solfedjio education platform.

## Milestone 01

- Expo + React Native + TypeScript
- Expo Router navigation
- onboarding + login skeleton
- 5-tab student navigation
- mobile-first design foundation

## Run

```bash
cd mobile
npm install
cp .env.example .env
npm start
```
